# 주차 만차 · 지연 제보 실동작 확인 (2026-11-15)

환경: KYSDESKTOP, Pleos 에뮬레이터 2대, 앱 0.15.1-follow-destination. 실제 실행 서버와 로컬 Ollama 사용.
검사 입력은 음성 인식 이후와 같은 /messages 요청으로 전송했으며 실제 마이크 발화 인식 정확도나 스피커 청취를 검증한 것은 아닙니다.

## 확인한 흐름
- “여기 주차장 꽉 찼어” → parking 분류(ollama:qwen3:4b) → 팔로워의 대체 주차장 검색 제안.
- 팔로워에서 검색 수락 → OSM 시설 후보 5개 표시 → 주차장 · OSM 74821 선택 → 안내 변경 수락.
- Pleos 내비 화면에서 목적지가 해당 주차장으로 변경됨을 확인. parking_applied 완료 이벤트까지 확인.
- “나 20분 정도 늦을 것 같아” → delay 분류 → 팔로워 화면에 “20분 정도 늦을 것 같습니다.” 표시. 시간과 불확실성 유지.
- 모델이 다른 분류를 반환해도 명확한 의미를 보호하는 규칙으로 보정할 수 있으므로 모든 결과가 AI 생성 문장은 아닙니다.

## 검사 중 발견하여 수정한 문제
- “주차장 자리가 없어”, “주차할 자리가 없어”, “주차 공간이 없어”처럼 조사가 있는 표현을 만차 요청으로 처리하지 못하던 분류 규칙 수정.
- “안 늦을 것 같아”, “늦지 않을 것 같아”, “늦을 것 같지 않아”를 지연 상태로 표시하지 않도록 수정.
- 만차 부정 문장은 주차장 추천을 유발하지 않도록 관련 회귀 검사 추가.
- Python 전체 196개 통과. 서버 반영 후 실제 Ollama로 주차 표현 및 부정 표현 재검사 통과.
- Android 코드는 이번 검사에서 변경하지 않음. 직전 빌드의 38개 검사 통과 상태 유지.

## 범위와 한계
- 후보는 목적지 주변 시설이며 실시간 주차 가능 대수는 조회하지 않습니다.
- 이번 검색은 실시간 시설 조회 대신 저장된 지역 OSM 시설 데이터로 완료됐으며 앱에도 이를 표시합니다.
- 지연 메시지를 전달하는 기능입니다. 발화한 20분을 도로 ETA에 자동 가산한 것으로 해석하면 안 됩니다.
- 마이크 인식 정확도, TTS 실제 청취, 실도로 주행은 이번 확인 범위에 포함하지 않습니다.
