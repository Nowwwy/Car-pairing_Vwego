# 맥락을 이해하는 주차 요청
사용자 요구: 목적지를 바꾼 후 주차가 어렵다고 말하면 바뀐 목적지 주변을 찾고, 정해진 발화/응답 이외의 표현도 이해한다.
기존 Kotlin/Pleos/로컬 qwen3:4b 환경을 유지한다. 키워드만 추가하는 접근은 간접 표현과 지시어를 해결하지 못한다. 외부 유료 모델 도입 대신 현재 로컬 모델에 실제 목적지·최근 본인 적용 기록·직전 발화를 전달한다.
주차 문제는 기본적으로 목적지 주변 대안 검색, 명시적 현재 위치 요청은 현재 위치 검색, 명시적 일행 전달은 전달로 구분한다. 대안 후보는 실제 색인 데이터만 쓰고 현재 목적지와 같은 주차장 반복을 제외한다. 주차 빈자리 정보는 확인되지 않았음을 표시한다.
음성 후보 선택/최종 확인도 모델이 표시 중인 선택지에 근거해 해석한다. 최종 적용 전 확인, 부정/애매한 동의의 재확인, 비동기 요청 중 목적지/모임 변경 시 폐기를 유지한다.
직전 발화는 같은 연결에서 5분 동안만 유지한다. 다른 모임/다른 차량의 변경 기록을 개인 목적지로 사용하지 않는다. 기존 만차 연락/지연/목적지 완료 알림 보존.
