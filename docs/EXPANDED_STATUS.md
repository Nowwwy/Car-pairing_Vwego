# 2026-11-13 확장 구현 인계

v0.7은 Pleos Connect 네이티브 Android 앱입니다. PC026의 두 에뮬레이터에 설치하고 실행했습니다. APK SHA256은 VALIDATION.json에 있습니다.

## 이번 확장

- 별도 출발지 GPS 실행기 유지: 판교 / 잠실 → 강남역 2번 출구.
- 외부 자동차 경로 시간에 휴게소/주유 체류 시간을 더해 증가/단축 비교. 안내 적용은 별도 수락 후 Pleos SDK로 수행.
- 주차장까지 차량 시간 + 정차 + 공동 목적지까지 도보 시간.
- 선택 학습 동의, 실제 수락 장소의 빈도/최근 이력 추천, 삭제.
- 층·구역·메모와 선택적 최신 좌표를 포함한 내 주차 기록.
- 모임 목적지 저장/재사용, 리더 위임, opt-in 주변 모임, 번호판 입력.
- QR 생성/이미지 읽기/deep link 초대. 참여자 개별 동의 유지.
- 공유 목적지 변경 제안과 일행별 수락.
- 보수적 사투리 텍스트 정리, 원문/결과/분류 출처 표시.
- SQLite 저장과 재시작 복구. 오래된 GPS/ETA를 복원하지 않음.
- P 외 상세 입력 차단, P→D 시 열린 상세창 닫기, 늦은 응답의 창 재표시 방지.

## 검증

Python 전체 56개 검사 통과. Android assembleDebug 성공 및 단위검사 3개 통과. 두 AVD 설치/실행, 모임 생성과 SDK 목적지 반영, 앱의 SDK ETA, P 확장 메뉴와 장소 종류 화면을 직접 확인했습니다. 모든 확장 화면의 실차/전체 시나리오 검증을 완료했다는 뜻은 아닙니다.

실제 서버 API를 통한 외부 계산:

- 판교→강남역 기본 주행 760.1초.
- 성원주유소 경유 주행 996초 + 주유 600초 = 1596초. 기본 대비 835.9초 추가.
- 별도 주차 좌표에서 강남역 도보 355.7초.
- 강남 실제 주유소 검색은 지역 OSM 스냅샷으로 대체되어 5개 후보 반환.

원본 결과는 LIVE_PROVIDER_VALIDATION.json. 실시간 교통을 포함하지 않습니다.

## 남은 범위

실시간 주차 재고/요금, 교통 정체, 전국 시설 가용성, 휴게소 방향별 접근성, 실제 마이크 사투리 인식, 음성 발음 교정, Gleo/HYBRID 인증, 임의 경로 이탈 자동 학습, 보행자 실시간 추적, 운영용 HTTPS/계정/푸시 서버는 미완료입니다. 1인칭 3D 화면에 Android 화면을 통합하는 기능은 이 네이티브 확장본에 포함하지 않았습니다.

Pleos 기본 내비의 흰 지도 문제를 SDK 제공자의 서버까지 고친 것은 아닙니다. 앱은 별도의 OSM 도로 지도를 사용합니다. 에뮬레이터 SDK ETA가 현실의 교통 ETA와 일치함을 보장하지 않습니다.
